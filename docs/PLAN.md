## Действия

- [x] Валидатор LLM: проверка «сухо → дождь» идёт по всему тексту, поэтому смешанный
  день (сухое утро, дождливый вечер) отбраковывается всегда — черновик не проходит
  собственную проверку, редактура выключена молча. Сверять окна дня построчно
  по эмодзи и закрыть регрессионным тестом.
- [x] Дефолт `OPENROUTER_MODEL` вернуть на `openai/gpt-oss-120b:free`: он сменился
  на модель без суффикса `:free`, ни в коммитах, ни в документах это не отмечено,
  и `.env.example` говорит обратное.
- [x] `fetchJson` не повторяет запрос на 4xx: сейчас 429 и 401 повторяются трижды,
  что бьёт по квотам провайдеров ровно вопреки принятому решению про кэш.
  Заодно `clearTimeout` в `finally`.
- [x] `npm run check` покрывает все модули: после разбора монолита `node --check`
  видит только `bot.js`, а `telegram.js`, `geocode.js` и `llm.js` не проверяются
  ничем — синтаксическая ошибка в них пройдёт гейт.
- [ ] Risk score чинится на месте: вернуть асимметрию регулярного маршрута (утро
  и вечер — езда, день мотоцикл стоит), убрать слово «поездка» из режима коммьюта
  и согласовать тело сообщения с вердиктом — сейчас оно берёт `rainMajority`,
  а вердикт считает по баллу.
- [ ] Тесты на изменённое поведение: «дождь только днём» и «слабый дождь утром
  у всех источников». Заменить проверки вида `/под вопросом|не ехать|крышей/` —
  они проходят на трёх взаимоисключающих вердиктах сразу.
- [ ] Документы: пересобрать `STATUS` в один экран состояния, записать найденное
