# HANDOFF

Что не закончено прямо сейчас. Перезаписывается; незавершённое чужое не стирается.

Кода в работе нет. Этап закрыт и развёрнут на Oracle: runtime-коммит `07ff6d1`,
`weatherbot.service` активен, `NRestarts=0`, 61 тест прошёл локально и на сервере.
Предыдущее дерево и снимок JSON-хранилища сохранены для отката; процедура деплоя теперь
записана в разделе Deployment в [CLAUDE.md](CLAUDE.md).

**Осталась ручная проверка владельцем (§13):**

1. Выполнить `/forecast` для регулярного сценария. Пока источники согласны, отдельного
   блока источников быть не должно; дождь только днём должен советовать крышу над
   стоянкой, а не запрещать сухую поездку утром и вечером.
2. Для плановой поездки на 8+ дней вперёд выполнить `/forecast`. В конце ожидается блок
   `📊 Прогноз дальний, поэтому источники приведены по отдельности:` со строками окон,
   где осталось хотя бы два источника.

После рестарта первый тик добавил две ожидаемые записи `scheduled window missed` для
регулярных сценариев с давно прошедшим временем. Ошибок запуска или Telegram polling
в журнале за проверенный интервал не было; реальные вызовы погодных провайдеров ещё
проверяются только ручным `/forecast`. Новый этап не начинать, пока владелец не посмотрит
живые сообщения.
